# Basic-Java
Completed labs in Java based on the book Introduction to Java Computer Programming and Problem Solving, Second Edition by [Chris Simber](https://rcbc.edu/people/chris-simber), Assistant Professor of Computer Science at Rowan College at Burlington County.

## Labs
* Developed a program to efficiently manage ticket sales 🎫 (Chapter 3)
* Utilized multiple files to modularize and manage different components of the program 📦️ (Chapter 5)
* Used arrays to collect, transfer, and manage data effectively 🗃️ (Chapter 6)
* Implemented a graphical user interface (GUI) to enhance user interaction with the system 💻 (Chapter 10)
